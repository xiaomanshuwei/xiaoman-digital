01

B2B CORPORATE WEBSITE

友豐貿易公司網站

以貿易公司的定位為核心，建立專業的企業形象與產品展示入口，讓訪客快速理解公司角色、產品線與聯絡方式。

案例介紹

本專案為精密測量儀器貿易公司規劃企業形象網站，將公司資訊、代理產品與商務聯絡內容整合在同一個平台。網站以清楚的資訊層級呈現企業服務與產品特色，協助潛在客戶快速找到所需資訊。

功能介紹

企業資訊展示呈現公司介紹、服務內容與聯絡資訊。
產品分類與介紹整理精密測量相關產品資訊，方便訪客瀏覽。
多語系內容提供繁體中文、簡體中文、英文及日文內容規劃。
型錄下載與響應式版面提供產品型錄入口，並支援不同尺寸裝置瀏覽。
企業形象產品展示多語系型錄下載RWD
我負責網站架構、視覺版型、產品展示與響應式頁面規劃。
重點將品牌介紹、產品資訊與商務聯絡集中在清楚的網站架構中。

02

BRAND & ORDER WEBSITE

拾香麵包房

從品牌故事、商品展示到訂單流程，將麵包房的視覺與實際訂購需求整合成一個容易操作的網站體驗。

案例介紹

本專案以「拾香麵包房」為主題，規劃具有品牌溫度的線上展示與訂購網站。透過一致的視覺風格、商品資訊與清楚的訂購動線，讓顧客能先認識品牌，再瀏覽商品並送出訂單。

功能介紹

品牌故事與形象呈現透過首頁與品牌內容傳達麵包房特色。
MENU／商品展示依商品內容呈現品項、圖片與價格資訊。
購物車與訂購流程讓顧客選擇商品、整理品項並提交訂單。
訂單資料接收整合訂單送出流程，方便店家接收顧客需求。
品牌故事MENU商品展示購物車訂單
我負責品牌視覺整理、商品頁面、訂購流程與手機版操作體驗。
重點讓顧客先認識品牌，再自然進入商品與訂購流程。

03

CUSTOM WEB APP

企業庫存管理系統

把實際倉儲工作流程轉成線上系統，整合出入庫、庫存、訂單、出貨序號與操作紀錄，降低人工查找與重複輸入。

案例介紹

本專案從實際倉儲作業情境出發，將原本分散的收貨、出貨、盤點與庫存查詢流程整合為線上管理工具。以料號與交易紀錄為核心，讓使用者能追蹤庫存異動，並減少重複登記及人工核對的負擔。

功能介紹

入庫／出庫登記記錄物料異動、人員、單號與備註等資訊。
庫存即時計算依入庫與出庫紀錄更新庫存數量，方便查詢。
訂單與出貨核對協助整理訂單資訊及出貨序號，降低重複登記風險。
操作紀錄與資料管理保留操作歷程，並透過資料庫集中管理系統資料。
Node.jsExpressPostgreSQL資料庫Web App
我負責需求整理、資料流程、前端介面、後端 API 與資料庫串接。
重點從「工作流程」出發，而不是只從畫面出發，讓系統真正貼近使用情境。
